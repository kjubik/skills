# Brainstorm

The user is unsure on how to proceed and wants possibilites suggested.

Think through what are the different approaches one could take when proceeding. For each viable approach create an independant suggestion. First write a brief, very concise argumentation on what is the mindset of the specific approach. Based on that generate the suggestion itself.
